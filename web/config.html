Serial Port
Serial Port 2 — LED Display

Second, independent serial port driving the TDM-800 LED display (see request/LEDBoard.md). Exposed to Lua as Serial2.* and wrapped by config/scripts/led.lua. Separate from the Citizen ID reader on Serial Port above.

Writes a real TDM-800 frame using the settings above — it does not need a Lua script running. ASCII only; the panel cannot render diacritics.
Modbus TCP

Addresses are no longer configured here — the running Lua script declares the points it uses with Modbus.RegisterInput(name, address) and Modbus.RegisterOutput(name, address), and those appear on the Dashboard. Inputs are read as discrete inputs (FC02), outputs as coils (FC01).

RFID Reader
ZK Access Controller

The card reader at the scan position, driven from Lua with zk.connect(). Nothing in the backend connects to it — these values are here so config/scripts/zkcard.lua can read them instead of carrying a site-specific address. Requires a Windows x86 build (the PullSDK is 32-bit only).

Leave empty if the controller has none.
RabbitMQ Broker

Message broker for publishing gateway events and receiving commands, reached from Lua as Mq.Publish() / Mq.Get() — see the Lua API Documentation. Note the default login is dev/devpass, not RabbitMQ's stock guest/guest: that user has to exist on the broker and be granted on the vhost.

Empty targets the default exchange (routes by queue name).

Card Reader Client API

Lets external card reader clients (USB/TCP/desktop/mobile) submit card UIDs to POST /api/card/input instead of talking to RFID hardware directly. See the Test Tools › Card Clients to manage individual client API-Keys.

Structured Logging

Business records written by scripts with Log.Write(type, data), stored in config/logs.db and searchable on the Logs › Structured Logs tab. The runtime log (Log.Info and friends) is unaffected by these settings.

Off by default. Turns on Log.Debug() and the gateway's diagnostic detail (serial open timings, raw traffic). Every line is a file write — leave it off in normal operation. Takes effect within a second of saving, no restart.

Software Update

Checks the release server for a newer build and offers it in a popup. Nothing is ever installed without someone clicking Update now. Packages are checked against the manifest’s SHA-256 and a detached signature before anything is unpacked; a release that fails to start is rolled back automatically. See docs/ota-update.md.

The gateway appends ?platform=&channel=&version=&device_id=. A static version.json works too — see the manifest formats in the docs.
Grace before the first check, so it does not compete with startup.
