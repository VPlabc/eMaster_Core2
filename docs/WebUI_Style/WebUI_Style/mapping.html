🔗 Data Source Mapping

📖 How Data Mapping Works

Step 1: Define a value name (e.g., "Temperature", "Pressure")

Step 2: Select data source (PLC via Modbus, OPC UA server, MQTT topic)

Step 3: Choose internal variable name for internal processing

Step 4: Select UI type to automatically generate monitor card or input field

Result: A new row appears in the Monitor dashboard with real-time data display!

⚡ Quick Mapping Workflow

1️⃣
Define Value Name

2️⃣

3️⃣

Choose how to display this value in the Monitor page
